# RegionHUD public website

This repository contains only the public RegionHUD website and approved public branding assets. RegionHUD is published by WeDidInstead. Application source, packages, binaries and private material are not included.

## Preview locally

Open `index.html` in a browser. All pages work without a build step. Alternatively, from this folder run `python -m http.server 8080 --bind 127.0.0.1` and visit `http://127.0.0.1:8080/`. Python is an optional preview tool, not a production dependency.

## Publish later with GitHub Pages

1. Create a public repository and upload the **contents of this folder** to its root, including `.nojekyll` and `assets/`. Do not upload the parent workspace or application project.
2. Commit to `main`. In repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
3. Wait for deployment. Use the website address reported by GitHub; no username or domain is configured in these files.
4. Check the home page, `privacy.html` and `support.html`, including images and navigation at the repository subpath, before using their URLs in Microsoft Store.

Project-repository URL pattern: `https://<github-user>.github.io/<repo>/`, with `privacy.html` and `support.html` beneath that address.

Official guide: [GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Public contact: wedidinstead@outlook.com

No framework, JavaScript, backend, external fonts, analytics, trackers or cookies are used by these website files. Assets load locally. GitHub Pages is a separate hosting service; the RegionHUD privacy page describes the Windows application. Nothing has been published as part of this preparation.
